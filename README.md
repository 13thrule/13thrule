### I build things that sense, and react before they think.

WiFi RF, LED light, brainwaves, an agent's own reasoning loop. Different domains, same instinct:
put a fast, reliable reaction path underneath the slow, smart one.

```
  signal ──┬──► reflex ───────────────► act      (fast, dumb, always on)
           │
           └──► think ──► decide ─────► act      (slow, smart, catches up)
```

## featured

**[Switchboard](https://github.com/13thrule/Switchboard-rust)** `Rust`
A real pub/sub message broker with zero-copy delivery, lock-free skip lists and cross-process
shared-memory transport. The most serious engineering I've done.

**[led-data-transmission](https://github.com/13thrule/led-data-transmission)**
A 12-LED ring transmits data as light; a webcam decodes it. 33-bit, self-syncing,
crosstalk-resistant protocol.

**[ANSE](https://github.com/13thrule/ANSE-Agent-Nervous-System-Engine)**
An agent runtime with a reflex arc that reacts before the LLM finishes thinking.

**[Nexus WiFi Radar V2](https://github.com/13thrule/Nexus-Wifi-Radar-V2)**
Passive WiFi analysis: device fingerprinting, hidden-network classification, threat scoring,
real time.

**[neuro-synchron](https://github.com/13thrule/neuro-synchron)** `WebGL` `JavaScript`
A single-file particle system that scales live to 16.7M points, with a real scheduler underneath
the loudest marketing copy I've ever written.

**[Persona Stage](https://github.com/13thrule/persona-stage)**
Fully local, fully offline. Gives any script a face and a voice, one HTTP call at a time.

The full story on each one, including the one place my own README oversold its own internals,
lives on the portfolio, not here.

## new in the workshop

**[project-aura](https://github.com/13thrule/project-aura)** `Python` `Rust`
Open-source ambulatory EEG platform for pre-seizure (pre-ictal) signature research, built around
the OpenBCI Cyton board.

**[rim-zomboid-bridge](https://github.com/13thrule/rim-zomboid-bridge)** `C#` `Lua`
State-sync between two live games with no shared runtime, sockets or shared memory. A RimWorld
colonist walks into Project Zomboid and comes home with a machete.

**[groovebox](https://github.com/13thrule/groovebox)** `Python` `C++`
An R4-controlled MIDI drum machine. The board handles buttons, pot and clock; the PC owns a full
step-sequencer GUI.

**[led-vault](https://github.com/13thrule/led-vault)** `C++`
A WiFi-controlled LED ring and matrix dashboard for the Arduino UNO R4 WiFi, with a companion PC
status light app.

**[cardsynth](https://github.com/13thrule/cardsynth)** `C`
A little synth for the M5Stack Cardputer-Adv, built on M5Stack's official demo firmware.

## earlier builds

**[Nexus WiFi Radar](https://github.com/13thrule/Nexus-Wifi-Radar)**
Where the radar started: real-time scanning, heat maps and audio sonar across Windows,
Raspberry Pi and a custom cyberdeck OS. My most-starred repo at 12, and built entirely with
AI-assisted development.

**[ZeroToken](https://github.com/13thrule/ZeroToken)**
A fully local agent builder powered by Ollama. It plans, patches and reviews offline before a
single cloud token gets spent.

**[Cortex-Github](https://github.com/13thrule/Cortex-Github)**
A real-time 3D brain fed by live GitHub public events. Every commit, push and fork fires a signal
pulse outward to its lobe.

**[Repo_Defender](https://github.com/13thrule/Repo_Defender)**
An arcade shooter that turns your GitHub profile into a battlefield. HTML5 Canvas.

**[Smart Wiring Watchdog](https://github.com/13thrule/Smart-Wiring-Watchdog-Digital-Diary-Mega-2560-)** `C++`
Replaces the multimeter beep test with a continuity mapper that logs pins into a live diary and
watches them for intermittent failures. Maybe 200 lines total, and it does its whole job.
